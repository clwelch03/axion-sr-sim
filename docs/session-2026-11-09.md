## Diagnosis of the blocker

The overall size of each mode's solution is set by one row: the outer
boundary condition `R_fund(r_end) = A × (outer series at r_end)`. Every other
equation is homogeneous in the size. With unknowns in units of `A`, that row
can move the residual only by the tail-to-peak ratio, about 1e-21 at
`r* = 1000` (α = 0.3), far below the Newton tolerance, so the solver cannot
distinguish the cloud from `R ≈ 0`. Evidence:
`validation/logs/domain_outer_debug_1000.log` — the *free* (linear, scale-free)
solve stalls with |F| ≈ 1e-11 and non-shrinking steps, returns ω₂₁₁ = 0.29487
instead of 0.29630, and a bulk profile so small that the energy-matched
amplitude comes out as 4e7.

The ratio of decay rates κ₂₁₁/κ₃₂₂ ≈ 3/2 is independent of α (hydrogenic), so
containment of |322⟩ and the normalization floor of |211⟩ coincide at every α;
this is not a small-α problem only.

## Approach: envelope scaling of the Newton system

Measure each tail unknown in units of an envelope `w_c(r)` that follows the
expected decay of its channel, and divide each residual row by the same
factor: solve `(D_r J D_c) y = −D_r F`, step `= D_c y`. In exact arithmetic
the discrete solution is unchanged; only the floating-point conditioning and
the convergence test (now on the scaled residual) change.

Scratch test (free single-mode |211⟩, a = 0.99, α = 0.3, `A = 1e-6`;
`κ = 0.047` envelope beyond r = 150; scripts in the session scratchpad):

| r*_max | tail / peak | unscaled | envelope-scaled |
|---|---|---|---|
| 400 | 4e-7 | correct ω | identical |
| 1000 | 5e-19 | collapses, ω off 1.4 % | ω to 2e-22 |
| 2000 | 3e-41 | wrong ω | cold seed fails; warm start from r*=1000: ω to 2e-22 |
| 4000 | 6e-82 | — | warm start: ω to 2e-22 |

Untested there: nonlinear two-mode problem with driven components. Observed:
peak per unit `A` drifts 3e-5 (400 → 1000) and 1.1e-4 (2000 → 4000); likely
MIRK4 error accumulated along the long tail at `max_step = 3.7` (confirmed
below, "Label drift explained").
